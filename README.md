# Wireless Charging Receiver (Type-C Output)

## Overview
This project is an **open-source wireless charging receiver module**, designed for DIY and consumer electronics.  
It follows the **Qi protocol** and provides **USB Type-C output**.  
When paired with a standard wireless charging transmitter, it can make most Type-C devices compatible with wireless charging.

The repository contains circuit schematics, PCB layout, Gerber files, and 3D-printed case design.

---

## Features
- **Supports Qi protocol**
- **USB Type-C male output**
- Compact design with integrated 3D-printed case
- Tested stable under continuous use
- Silent operation (no audible noise)
- Thermal performance within datasheet requirements

---

## Specifications
- **Physical Dimensions**:  
  - Diameter (with case): 55.6 mm  
  - Thickness: 6.1 mm  
  - Weight: 16 g  

- **Electrical Performance**:  
  - Output: 5 V / 1 A  
  - Tested stable at ~4.5 W continuous load  

- **Coil**:  
  - Inductance: 12.6 µH (common receiver coil type)  
  - Dual isolation layers: board copper pour + magnetic sheet + coil magnetic sheet  

- **Materials**:  
  - Case: PETG (3D printed, 0.12 mm layer height, random Z-seam)  
  - Capacitors: X7R (low temperature drift, stable under wireless charging frequency)
